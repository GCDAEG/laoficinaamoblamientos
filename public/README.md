# Recursos del sitio

Guardá aquí los recursos aprobados de cada encargo. Se sirven desde `/`:
por ejemplo, `public/images/equipo.webp` se referencia como `/images/equipo.webp`.

La base no incluye fotografías ni logos de clientes. La ilustración de la demo
está hecha con CSS y el favicon genérico está en `src/app/icon.svg`; ambos fueron
creados para este ejemplo, sin recursos de terceros.

Al incorporar archivos, documentá origen, autor, licencia o autorización cuando
se conozcan. Conservá proporciones, optimizá peso y dimensiones y definí texto
alternativo según el uso. No des por confirmados derechos pendientes.
